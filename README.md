# sales-ej

電子ジャーナル（EJ）ファイルを解析し、カテゴリ別の販売数・販売額を集計するツールです。
WCOOP向けに構築されており、メインレジ（XE-A207）とサブレジ（XE-A147）の両フォーマットに対応しています。

## 機能

- EJFILE.TXT（Shift-JIS）のアップロード・自動デコード
- メイン/サブレジの自動判定（`責任\d+` の有無による）
- 日付範囲指定での絞り込み
- カテゴリ別販売数・販売額の集計テーブル表示
- ジャーナル原文の表示
- 日付変更による再計算

## ファイル構成

```
sales-ej/
├── index.html              # メインページ（エントリポイント）
└── files/
    ├── css/
    │   ├── style.css       # サイト共通スタイル
    │   ├── sales.css       # 販売分析ページ共通スタイル
    │   ├── sales-a.css     # メインレジ固有スタイル（現在空）
    │   └── sales-b.css     # サブレジ固有スタイル（現在空）
    ├── img/
    │   └── sales_logo_white.png
    └── js/
        ├── sales.js        # 共通UI・ページ操作・自動判定ロジック
        ├── sales-207.js    # メインレジ固有パーサ（XE-A207）
        └── sales-147.js    # サブレジ固有パーサ（XE-A147）
```

## レジ判定ロジック

ファイル内に `責任\d+`（例: `責任01`）が含まれる場合はメインレジ、含まれない場合はサブレジとして処理します。

## パーサの違い

| | メインレジ (XE-A207) | サブレジ (XE-A147) |
|---|---|---|
| 方式 | pending record方式 | トランザクションバッファ方式 |
| 取消 | `解除機能により中止` で直前レコード破棄 | トランザクション全体を破棄 |
| 訂正 | `内戻-` / `内訂-` / `訂 -` | `取引後訂正` でトランザクション全品マイナス計上 |

## 読み込みJSの順序

```html
<script src="files/js/sales-207.js"></script>  <!-- window.SalesPageMain を定義 -->
<script src="files/js/sales-147.js"></script>  <!-- window.SalesPageSub を定義 -->
<script src="files/js/sales.js"></script>       <!-- 自動判定・UI制御 -->
```
