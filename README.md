# sales-ej

電子ジャーナル（EJ）ファイルを解析し、カテゴリ別の販売数・販売額を集計するツールです。
WCOOP向けに構築されており、メインレジ（XE-A207）とサブレジ（XE-A147）の両フォーマットに対応しています。

## 機能

- EJFILE.TXT（Shift-JIS）のアップロード・自動デコード
- メイン/サブレジの自動判定（`責任\d+` の有無による）
- 日付範囲指定での絞り込み（終了日はオプション、デフォルトは開始日と同日）
- カテゴリ別販売数・販売額の集計テーブル表示
- 現金・クレジット別の入金合計表示
- ジャーナル原文の表示
- 日付変更による再計算
- TXT / PDF / Excel 形式での出力（データ範囲選択可）
- 一部入金後に解除されたトランザクションの警告表示

## レジ判定ロジック

ファイル内に `責任\d+`（例: `責任01`）が含まれる場合はメインレジ、含まれない場合はサブレジとして処理します。

## パーサの違い

| | メインレジ (XE-A207) | サブレジ (XE-A147) |
|---|---|---|
| 方式 | pending record方式 + トランザクションスナップショット | トランザクションバッファ方式 |
| 解除機能により中止 | トランザクション開始時点にロールバック（売上・入金ともに取り消し） | トランザクション全体を破棄 |
| 訂正 | `内戻-` / `内訂-` / `訂 -` | `取引後訂正` でトランザクション全品マイナス計上 |
| 倍数戻品 | `66x -2` + `内戻-132` → 数量-2として計上 | — |

## 一部入金後解除トランザクションについて

XE-A207の仕様として、一部入金後に解除機能を使用するとレジは残額も自動補填して会計完了扱いにします。
このツールではそのトランザクションをロールバック（売上・入金ともに取り消し）して実態に即した集計を行いますが、レジ日計との差異が生じます。
該当トランザクションがある場合は結果画面に警告として表示されます。

## 出力機能

| 形式 | サマリーのみ | サマリー+詳細 | ジャーナル |
|---|---|---|---|
| TXT | ✓ | ✓ | — |
| PDF（印刷） | ✓ | ✓ | — |
| Excel | ✓ | ✓ | ✓（別シート） |
